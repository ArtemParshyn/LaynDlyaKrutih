# Установка и запуск модуля 1С

## Запуск одной командой

Выполнять можно из любой папки PowerShell. Укажите путь к папке файловой базы 1С:

```powershell
powershell -ExecutionPolicy Bypass -File "D:\projects\LaynDlyaKrutih-1c\1CIntegration\install-1c.ps1" "D:\projects\LaynDlyaKrutih-1c\1CBase" "http://127.0.0.1:3000"
```

Или CMD:

```cmd
1CIntegration\install-1c.cmd "D:\projects\LaynDlyaKrutih-1c\1CBase" "http://127.0.0.1:3000"
```

Скрипт скачает `SendStatement.epf` прямо в папку указанной файловой базы и откроет его в режиме предприятия. Он не меняет конфигурацию базы и не хранит API-токен внутри неё.

## Скачать модуль с сайта отдельной командой

После входа в API-кабинет скачайте `SendStatement.epf` кнопкой «Скачать модуль 1С». Либо выполните в PowerShell:

```powershell
$p = "D:\projects\LaynDlyaKrutih-1c\1CIntegration\SendStatement.epf"
Invoke-WebRequest "http://127.0.0.1:3000/SendStatement.epf" -OutFile $p
```

Для удалённого сайта замените адрес на адрес сайта. Затем откройте файл в 1С через «Файл → Открыть» или запустите `install-1c.ps1`.

## Распространение

Передайте пользователю папку `1CIntegration` (или архив с ней). Пользователь копирует её на свой компьютер, указывает путь к собственной файловой базе в команде, затем в форме вставляет персональную ссылку из API-кабинета и путь к CSV.

Если нужно встроить команду непосредственно в интерфейс конфигурации, это делается через Конфигуратор отдельно для конкретной конфигурации. Универсально установить такую команду одной командой в произвольные базы нельзя: конфигурации и права доступа различаются.
