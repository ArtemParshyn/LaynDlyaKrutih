# Обработка 1С для отправки банковской выписки

Это исходник внешней обработки, потому что готовый бинарный `.epf`/`.dt` нельзя корректно создать без установленной платформы 1С на этом ПК.

## Настройка
1. Откройте конфигуратор 1С → Файл → Новый → Внешняя обработка.
2. Создайте форму с реквизитами:
   - `АдресБэкенда` (Строка) = персональная ссылка выбранного пульса из API-кабинета сайта (в ней уже есть `user_id`, `pulse_id` и токен)
   - `Токен1С` (Строка) = оставить пустым, если вставлена персональная ссылка
   - `ИдентификаторПользователя` (Число) = можно оставить 0, если ID есть в ссылке
   - `ПутьКCSV` (Строка)
3. Добавьте команду/кнопку `ОтправитьВыписку` и вставьте код из `Module.bsl` в модуль формы.
4. Укажите путь к CSV и нажмите кнопку.

API-кабинет профиля выдаёт отдельную ссылку для каждого пульса. Поэтому в форме 1С достаточно вставить ссылку нужного пульса и путь к CSV. Никому не пересылайте ссылку: она является секретом доступа.

Текущие тестовые данные:
- email: `test1c@gmail.com`
- ID пользователя: `4`
- endpoint: `POST /integration/1c/statements`
- ссылка также содержит `pulse_id`, поэтому выписка попадёт только в выбранный пульс;
- запрос использует `X-1C-Token` и `X-User-ID`, отдельный JWT для 1С не нужен.

Для production замените токен и используйте HTTPS.
