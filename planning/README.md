# Планы

Хранит то, чего в выписке ещё нет: счета, налоги, ручной ввод. Сценарии «что если» сюда не пишутся.

Вход зовёт сервис по внутренней сети и передаёт номер компании в заголовке `X-User-ID`. Без заголовка ответ 401.

| Метод | Адрес | Ответ |
|---|---|---|
| `GET` | `/events` | Будущие события массивом, не обёрткой |
| `POST` | `/events` | Сохраняет одно событие, ответ 201 |
| `GET` | `/health` | `{"status":"ok"}` |

Сумма в копейках, больше нуля. Дата `YYYY-MM-DD`.

```env
PORT=8082
DB_HOST=planning-postgres
DB_PORT=5432
DB_USER=planning
DB_PASSWORD=secret123
DB_NAME=planning_db
```
